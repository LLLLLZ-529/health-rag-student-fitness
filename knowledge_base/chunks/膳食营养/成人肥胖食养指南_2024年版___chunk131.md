高强度≥6.0MET。

基础代谢率预测公式： 女性基础代谢率=655+9.5×体重（kg）+1.8×身高（cm）-4.7×年龄（岁） 男性基础代谢率=66+13.7×体重（kg）+5.0×身高（cm）-6.8×年龄（岁） 身体活动能量消耗（包含基础代谢）计算公式： MET 值(kcal/(kg·h))×体重(kg)×活动时长(h) 总能量消耗预测公式： 基础代谢率×全天中非身体活动时间占比+身体活动能量消耗+食物热效应 注：食物热效应约占每日总能量消耗的 10% |                                                                                                                                                    |                                                                               |                                       |

注：引自《健康成年人身体活动能量消耗参考值》(T/CSSS 002—2023)
