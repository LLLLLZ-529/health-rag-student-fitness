# 大学生体质健康指数（HI）趋势阈值专家评估材料

> 评估目的：确认 HI 趋势斜率的分类阈值是否合理，为后续健康状态分类与早期预警提供专家依据。

---

## 一、项目背景

本研究基于某高校 36,059 名本科生 4 年（大一至大四）体测纵向数据，构建"健康状态分类 → 早期退化预警 → 个性化干预推荐"三模块系统。

健康状态标签采用 **水平（Level）× 趋势（Trend）** 的 3×3 九类划分：
- **水平**：由最新学年 HI 总分决定（低 / 中 / 高）
- **趋势**：由 HI 逐年变化斜率决定（下降 / 稳定 / 上升）

其中**趋势阈值目前为研究团队自定的 ±0.1**，亟需体育教育/运动医学领域专家确认其合理性。

---

## 二、HI 健康指数计算方法

### 2.1 单项指标方向校正

| 指标 | 方向 | 说明 |
|---|---|---|
| BMI | 倒 U 型 | 距 [18.5, 23.9] 区间距离取负，偏离正常范围越远得分越低 |
| 肺活量 | +1 | 越大越好 |
| 50 米跑 | −1 | 时间越短越好，取负后越大越好 |
| 立定跳远 | +1 | 越大越好 |
| 坐位体前屈 | +1 | 越大越好 |
| 耐力跑 | −1 | 时间越短越好，取负后越大越好 |
| 力量（引体向上/仰卧起坐） | +1 | 越大越好 |

### 2.2 分层标准化

在 **性别 × 年级** 组内进行 Z-score 标准化（ddof=0），消除性别差异和年级自然增长带来的群体偏差。

### 2.3 国标加权求和

| 指标 | 权重 | 依据 |
|---|---|---|
| BMI | 0.15 | 《国家学生体质健康标准》权重体系 |
| 肺活量 | 0.15 | |
| 50 米跑 | 0.20 | |
| 立定跳远 | 0.10 | |
| 坐位体前屈 | 0.10 | |
| 耐力跑 | 0.20 | |
| 力量 | 0.10 | |

HI 总分范围约为 [-1, 1]（标准化后加权和）。

### 2.4 趋势斜率 HI_slope

对每位学生的 4 年 HI 总分做线性回归，取斜率作为 HI_slope：
- HI_slope > 0：健康水平逐年上升
- HI_slope ≈ 0：健康水平稳定
- HI_slope < 0：健康水平逐年下降

## 四、需专家评估的核心问题

### 问题 1：阈值合理性

HI_slope 的绝对值变化达到多少，才可被认为是**具有临床/体育教育意义的显著变化**？

- 当前 ±0.1 对应的是：4 年间 HI 总分累计变化约 0.3（斜率 × 3 年跨度）
- HI 总分标准差约为 0.18，±0.1 约等于 0.55 个标准差
- 从分布看，±0.1 恰好接近 25%/75% 分位（−0.103 / +0.106）

**专家判断参考**：
- [ ] ±0.1 合理，维持不变
- [ ] 应更严格（如 ±0.15 或 ±0.2），减少"伪趋势"
- [ ] 应更宽松（如 ±0.05 或 ±0.08），更早捕捉变化
- [ ] 建议其他阈值：______
- [ ] 不应用固定阈值，建议按分位数划分（如上下 25%）

### 问题 2：趋势分类方式

当前采用**三分法**（下降/稳定/上升），是否合理？

- [ ] 三分法合理
- [ ] 应简化为二分法（下降 vs 非下降），更符合预警场景
- [ ] 应细分为更多等级（如显著下降/轻度下降/稳定/轻度上升/显著上升）
- [ ] 建议其他方式：______

### 问题 3：阈值是否应分层

趋势阈值是否应因**性别、年级、基础水平**而异？

例如：
- 男生和女生的 HI_slope 分布是否有显著差异？
- 大一至大二的变化波动是否大于大三至大四？
- 高水平学生的小幅下降是否比低水平学生的同等下降更值得关注？

- [ ] 统一阈值即可，无需分层
- [ ] 应按性别分层
- [ ] 应按基础水平分层
- [ ] 应按年级分层
- [ ] 建议其他分层方式：______

### 问题 4：class 6（高-下降）的合理性

高水平但持续下降的学生仅 93 人（0.3%），是否符合实际情况？

- [ ] 合理，高水平学生本身基数小且自律性强，持续下降确实罕见
- [ ] 不合理，可能是阈值过严导致漏判
- [ ] 不确定，需要查看具体案例

### 问题 5：早期预警的时间窗口

本研究用**大一+大二数据预测大四是否退化**，预警提前量约 2 年。从体育教育角度：

- 提前 2 年预警是否有实际干预价值？
- 是否需要更早（如仅用大一数据）或更晚（如用大三数据）的预警？
- 干预的最佳时间窗口是什么？

## 五、补充说明

1. **HI 总分并非直接等于体测总分**，而是经过方向校正、分层标准化、国标加权后的综合指数，范围约 [-1, 1]。
2. **HI_slope 为线性回归斜率**，假设健康变化为线性趋势。实际中可能存在非线性变化（如大二突降后大三回升），线性斜率可能掩盖此类模式。
3. **当前所有实验结果均基于 ±0.1 阈值**，若专家建议调整阈值，需重新生成标签并重跑全部实验。
